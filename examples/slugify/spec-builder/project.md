# Project Context

## Purpose
A tiny Python text-utilities library used to demonstrate the Spec-Builder skill
pipeline end-to-end.

## Tech Stack
Python 3 (stdlib only). Tests run with `python3 tests/test_slugify.py`.

## Conventions
- Source in `src/`, tests in `tests/`.
- Pure functions, type hints, docstrings.
- Keep changes minimal and scoped to the task.

## Domain Glossary
- **slug**: a URL-safe, lowercase, separator-joined form of a string.
